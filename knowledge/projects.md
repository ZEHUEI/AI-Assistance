# RotorAI

## Overview

RotorAI is an AI-powered industrial inspection platform developed by Ze Huei Lim.

The platform automatically detects corrosion and structural cracks from industrial inspection videos using deep learning and computer vision.

---

## Technologies

Python

TensorFlow

YOLOv8

OpenCV

3D Gaussian Splatting

---

## Features

Real-time corrosion detection

Real-time crack detection

Industrial video inspection

Automatic frame preprocessing

Noise reduction

Brightness normalization

3D visualization of prediction results

---

## Achievements

Developed an automated preprocessing pipeline.

Improved model accuracy by approximately 15% under low-light industrial environments.

Mapped AI predictions onto 3D engineering models using Gaussian Splatting.
